## 重要读取说明
1. 不得只看 README.md 或个人档案摘要就声称完成读取。
2. 必须检查两个聊天记录目录的全部层级和文件；每次读取时以 main 分支最新目录为准。
3. 两个目录中的 README.md 只说明归档方式，不代表实际聊天记录。
4. 如果目录为空、只有 README，或因上下文限制无法读完，必须明确报告实际情况和未读取内容。
5. 读取完成后，应报告两个目录分别发现和读取的文件数量。

本仓库为公开仓库。档案内容以用户明确提供的信息为准；涉及他人的内容会区分已确认事实与用户个人判断，并避免记录不必要的敏感隐私。
