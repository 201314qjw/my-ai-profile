# DeepSeek 对话记录

用于保存与 DeepSeek / DeepSeek Harness 的原始对话记录。

## 归档规则
- 按年份、月份分类，例如：`2026/2026-11/`
- 每个独立会话保存为一个 Markdown 文件。
- 尽量保留日期、会话标题、用户消息和 AI 回复。
- 项目代码、配置和附件可单独归档，并在对话文件中注明路径。
- 涉及密码、API Key、访问令牌及其他敏感内容时，先脱敏，不要上传。

## 重要说明
此目录目前仅建立结构，尚未导入历史聊天记录。DeepSeek Harness 的会话不会因为建立此目录而自动同步；需要通过导出或受支持的自动化流程导入。
